# Personal Portfolio Site Plan

## Direction

Build a static, root-level Jekyll portfolio for **Bhavya Berlia** at
`bhavyaberliaa.github.io`. The site presents Bhavya as a strategy, operations,
and product leader who works well in ambiguous 0-to-1 environments.

The visual direction is **funky, confident, and editorial** rather than
corporate: a light-first palette, expressive type pairing, strong hierarchy,
crisp borders, and small moments of personality. A dark theme is included as a
user-controlled alternate theme.

## Pages

- **Home** — positioning statement, experience highlights, primary call-to-action,
  and links to About, Experience, and Contact.
- **About** — the supplied career narrative and working style.
- **Work Experience** — Rocket Learning and Samagra, using only supplied facts,
  with clearly marked placeholders for missing details.
- **Contact** — invitation to connect, public email mailto placeholder, and GitHub.

## Technical choices

- Plain HTML, CSS, Markdown, and minimal JavaScript only.
- No backend, database, form service, tracker, framework, package manifest, or
  third-party runtime dependency.
- GitHub Pages-compatible Jekyll build from the `main` branch and repository root.
- Semantic landmarks, visible focus states, accessible contrast, responsive
  layouts at 375px and 1280px, and reduced-motion support.
- SEO metadata, canonical URL, Open Graph metadata, sitemap, robots file, and
  favicon included.

## Content rules and assumptions

- Use only supplied facts: Haas, Rocket Learning, Samagra, AI transformation
  strategy, Google and OpenAI partnerships, the 0-to-1 product, 15M+ learners,
  public systems work, and the voice AI app.
- Do not invent dates, employers, clients, metrics, URLs, or achievements.
- Keep the email address as a clearly labeled placeholder until one is supplied.
- The GitHub user site repository is assumed to be `bhavyaberliaa.github.io`.
