# Bhavya Berlia portfolio

This project must remain a static, root-level Jekyll site for
`bhavyaberliaa.github.io`, publishing from `main` and `/ (root)`.

- Keep the website files at the repository root, including `index.md`,
  `_config.yml`, `_layouts`, `_includes`, and `assets`.
- Do not add React, Vite, Node applications, package.json, monorepos, a database,
  backend, CMS, trackers, or a separate preview app.
- Page content lives in Markdown with YAML front matter. Layouts and includes
  own the HTML design. JavaScript is limited to the theme toggle.
- Never source personal facts from reference URLs; use supplied biography text.
- Never invent achievements, dates, employers, titles, metrics, or projects.
- The internship timeline is the user's supplied summer 2026 text; do not silently
  change it based on the current date.
- Preview the actual Jekyll site with `bundle exec jekyll serve`.
- Publish through GitHub Pages, not a separate Replit application.
